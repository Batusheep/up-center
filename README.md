# UP Center — концепт редизайна главной

Концепт новой главной страницы up-center.ru по техническому заданию. Чистые HTML, CSS и JS без сборки: откройте `index.html` в браузере.

## Что есть

- Закреплённая шапка, которая уменьшается при прокрутке, выпадающие меню «OTMlar» и «Xizmatlar», переключатель языка UZ / TJ / RU
- Мобильное меню (бургер) и плавающая кнопка мессенджера на телефоне
- Секции: первый экран с видео, цифры, «Biz kimmiz?», каталог вузов с фильтром по направлению и городу, услуги, шаги, отзывы, FAQ с ответами, форма заявки
- Форма: проверка обязательных полей, согласие на обработку данных, экран «Rahmat» (на сервер не отправляет)
- Подвал со ссылками на страницы вузов, услуг и контакты
- Адаптив: десктоп 1440 px, планшет, мобайл 375 px

Другие страницы не свёрстаны: ссылки на них ведут на будущие адреса (`/universitetlar/...`, `/xizmatlar/...`, `/aloqa` и т. д.).

## Что заменить перед показом клиенту

- **Цвет акцента:** `--accent` в `styles.css` сейчас условный фиолетовый. Снять точный hex с текущего сайта пипеткой
- **Фото:** галерея «Biz kimmiz?» (`img/about/`), фото вузов (`img/unis/`) и ролик на первом экране взяты с up-center.ru. Заглушками остались только фото в блоке цифр
- **Отзывы:** карточки «Talaba ismi» — заглушки, заменить реальными отзывами клиента
- **Ответы FAQ:** черновики, сверить с клиентом
- **Telegram:** ссылка пока `#`, нужен адрес аккаунта. WhatsApp ведёт на номер с сайта
- **Тексты на узбекском:** вычитать носителю языка
